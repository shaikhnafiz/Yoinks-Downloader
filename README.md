# 🚀 Yoinks Downloader - Windows Launcher
See how to Install : https://youtu.be/6XbqijPA-QQ?si=uKbjxS-qMqYj8_T4
> **Yoink any video. Paste. Yoink. Done.**

A simple Windows launcher and wrapper for [Yoinks](https://github.com/pablostanley/yoinks), designed to make setup and usage seamless for Windows users.

Download videos from **YouTube, X/Twitter, Instagram, Threads, TikTok, and 1,800+ other supported websites** through Yoinks without ever touching a command line.

---

## ✨ Features

- **Simple Windows Launcher**: Executable files to handle everything.
- **Automatic Node.js Setup**: Detects and installs Node.js if missing.
- **Dedicated Workflows**: Separate launchers for Video, Audio, and Playlist downloads.
- **Easy-to-Use Menu**: Intuitive terminal menu interface.
- **Zero Configuration**: No manual command-line setup required after installation.

---

## 📦 Included Files

| File | Description |
|------|-------------|
| `Install NodeJS.exe` | Installs Node.js if it is not already installed |
| `Yoinks Downloader.exe` | Launches the Yoinks downloader menu |

---

## 🚀 How to Use

### 1. First-Time Setup
Run the following executable to set up the environment:
```text
Install NodeJS.exe
```
The installer checks whether Node.js is already installed:
- **Installed:** No action is performed.
- **Not Installed:** Node.js will be installed automatically.

*(You only need to do this once.)*

### 2. Start Yoinks Downloader
After Node.js is ready, run:
```text
Yoinks Downloader.exe
```
You will be greeted with a simple menu:
```text
============================================
             YOINKS DOWNLOADER
============================================

[1] Video Download
[2] Audio Download
[3] Playlist Download
[4] Exit
```

---

## 🎬 Download Workflow

Select an option from the menu (`[1]`, `[2]`, or `[3]`). The launcher will automatically start Yoinks for the corresponding task (Video, Audio, or Playlist).

1. **Yoinks opens automatically.**
2. **Paste your URL** inside Yoinks.
3. **Choose your preferences** (resolution, format, etc.).
4. **Download** continues directly through Yoinks.

*Note: Once Yoinks is closed, the launcher will automatically close as well.*

---

## 📁 Output Folder

By default, downloaded files are saved to your **Windows Downloads** folder.
> *Note: The output folder selection option depends on the version of Yoinks being used.*
